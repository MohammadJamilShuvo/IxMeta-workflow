# Reference database policy

Taxonomic databases are part of the analytical method and must be versioned.

## Kraken2/Bracken

Recommended starting point for broad discovery: a current PlusPF-style database containing archaea, bacteria, viral, plasmid, human, UniVec Core, protozoa and fungi where computational storage permits.

Record for every analysis:

- database distribution/name;
- build date;
- download date;
- source URL;
- taxonomy build if provided;
- checksum or immutable archive identifier where available.

Do not compare studies using differently built databases without documenting the difference.

## Candidate references

Candidate references should be curated deliberately. Prefer complete/reference/representative genomes when appropriate, but evaluate whether one reference captures the diversity of the target lineage. For ambiguous taxa, map to a panel of related pathogenic and endosymbiotic genomes rather than a single sequence.
